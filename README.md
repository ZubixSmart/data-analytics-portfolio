# Data Analyst Portfolio Website

A responsive, one-page portfolio website built with HTML and CSS.

## Quick start
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Replace `Anyogu Anthony Azubuike` and the sample email, LinkedIn and GitHub links.
4. Review every experience and project description to ensure it accurately reflects your work.
5. Add screenshots and links to completed project files as you finish them.

## Publish with GitHub Pages
1. Create a GitHub repository named `data-analytics-portfolio`.
2. Upload `index.html`, `styles.css`, and this README to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public website address after deployment.
